## ✨ Особенности игры
* **Классический геймплей:** Прыжки, рывки и исследование уровней.
* **Стиль:** Красочная 2D-графика и плавная анимация.

## 🛠 Технический стек
* **Ядро:** Godot Engine 4.x
* **Язык:** GDScript
* **Инструменты:** Aseprite (арт), Audacity (звук)

## 📂 Структура проекта
Проект организован по четкой структуре для удобства разработки:
* **`src/`** — Исходный код и сцены.
* **`docs/`** — Документация, дизайн-документ и концепты.

## 🚀 Как запустить проект
1. Убедитесь, что у вас установлен **Godot Engine 4.x**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/lloreley/SKoG-project.git
   ```
3. Откройте Godot, нажмите "Import" и выберите файл project.godot.
4. Нажмите кнопку "Play" (или клавишу F5) для запуска.
